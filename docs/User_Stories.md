# User Stories

### US-01 — Monitor SLA Performance
**As an Operations Head,** I want to monitor SLA compliance so that I can identify whether service performance is meeting expectations.

**Acceptance:** total requests, compliant requests, breaches and compliance % are displayed consistently.

### US-02 — Identify High-Risk Request Types
**As an Operations Manager,** I want to compare request types so that I can prioritize problematic categories.

**Acceptance:** volume, SLA compliance, average TAT and P90 TAT are available by request type.

### US-03 — Compare Team Performance
**As an Operations Manager,** I want to compare teams so that I can identify performance gaps.

**Acceptance:** team SLA compliance, TAT and workload can be compared with common definitions.

### US-04 — Investigate Delays
**As a Team Lead,** I want to distinguish queue time from processing time so that I can determine where delays occur.

**Acceptance:** queue and processing time can be calculated and segmented.

### US-05 — Understand Rework Impact
**As a Team Lead,** I want to compare reworked and non-reworked requests so that I can assess rework's contribution to delays.

**Acceptance:** TAT and SLA performance are compared for both populations.

### US-06 — Identify Root Causes
**As a Business Head,** I want the main contributors to SLA breaches quantified so that I can make informed decisions.

**Acceptance:** drivers are evidence-based and linked to recommendations.

### US-07 — Track Improvement
**As an Operations Head,** I want to monitor KPIs after process changes so that I can measure whether interventions work.

**Acceptance:** baseline, target and post-change KPIs can be compared.
